GILDED FATE: COMBAT VFX AND ENEMY ANIMATION POLISH
===================================================

This update only changes how combat looks (presentation). It does not change
rules, cards, damage, AI, saves or balance.

HOW TO APPLY (GitHub website)
1. Open https://github.com/riverhine1-max/gilded-fate
2. Click "Add file" > "Upload files".
3. Drag the "Assets" and "Docs" folders from this zip into the page. GitHub
   keeps the folder paths, so each file replaces the one at the same path.
4. Commit with a message such as "Combat VFX polish + enemy animations".
5. Open the project in Unity 6000.5.9f1 and let it recompile.

HOW TO APPLY (git, alternative)
  git apply vfx-polish.patch
