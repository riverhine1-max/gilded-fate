# Actual new narration

All completed WAVs are new Arthur preset performances at native normal pace. They are mono, 48 kHz, 24-bit PCM containers converted from 16-bit provider recordings. Gain normalization is constant within each source performance and never stretches speech. Format, actual sample duration, clipping, hashes and canonical text are checked.

Some initial recordings use CTC forced alignment with independent ASR. The remaining recordings use local small.en Whisper attention/DTW word timestamps, checked by exact transcription of each delivered crop. Analysis padding is removed from measured offsets. The per-line alignmentMethod describes the actual method; no typing-speed-derived timings are included. Timing resolution is approximately 20 ms, not a guarantee of phonetic onset accuracy to one sample. All final intervals refer to the exact delivered WAV.

The alternative verifier imports no ONNX Runtime, disables VAD and hub telemetry, and reads local model weights; it sends no such telemetry. Only user-authorized new generation recordings were downloaded for processing.

Do not mark a rewritten or localized text ready against an old recording. Keep narration and the displayed text canonical together.

Revelation, scene and correction IDs match the actual Prompt 1 catalog. assetLineKey is an authoring locator; new audio line IDs derive from the reserved scene ID and explicit new block key. Keep the suggested WriteBlock command IDs when authoring the scenes, or update the binding without altering text or audio. Scenes are not registered by this content task.
